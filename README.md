# Kill the Cockroaches Game

A fun and engaging web-based game where players must eliminate cockroaches within a time limit. Built as a Progressive Web App (PWA) for cross-platform compatibility and offline play.

## 🎮 Game Overview

- **Title**: Kill the Cockroaches
- **Genre**: Action/Casual
- **Platform**: Web (PWA)
- **Target Audience**: Casual gamers of all ages
- **Developer**: Jezreel Douglas

### Features

- 90-second fast-paced gameplay
- Progressive difficulty with increasing spawn rates
- Achievement system with 10 different ranks
- Engaging sound effects and background music
- Installable as a PWA for offline play
- Responsive design for all devices
- Touch-optimized for mobile play

## 🚀 Technologies Used

- HTML5
- CSS3 (with modern features like CSS Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Progressive Web App (PWA) technologies
- Service Workers for offline functionality
- Web Audio API for sound effects

## 📱 Installation

1. Visit the game URL in a modern web browser
2. Click the "Install Game" button or use browser's install prompt
3. The game will install on your device and can be played offline
4. For mobile devices, the game can be added to home screen

## 🎯 How to Play

1. Click "Start Game" to begin
2. Click or tap on cockroaches to eliminate them
3. Score points by killing as many cockroaches as possible in 90 seconds
4. Achieve different ranks based on your performance
5. Use the mute button to toggle sound
6. Click "Play Again" to restart after game ends

## 🏆 Achievement System

The game features 10 achievement ranks:
- 200+ kills: The Exterminator Supreme
- 180+ kills: Plague Purger
- 160+ kills: Vermin Vanquisher
- 140+ kills: Insect Incinerator
- 120+ kills: Bug Butcher
- 100+ kills: Apocalypse Bringer
- 80+ kills: Legendary Exterminator
- 60+ kills: Infestation Hunter
- 40+ kills: Bug Basher
- 20+ kills: Roach Rookie
